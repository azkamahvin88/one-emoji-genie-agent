One emoji that stands for an AI agent: the genie 🧞. An agent acts on your behalf — you ask, it does the work — the way a genie grants a wish. One glyph, no caption: it reads instantly, says how the agent works, and stays far from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```
